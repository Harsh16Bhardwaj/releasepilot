---
name: rollout-planning
description: Propose measurable progressive release stages and human authorization requirements for an analyzed PR.
---

Use only supported flag keys and configured metrics. Default stages are 5/25/50/100 percent, 30 seconds minimum, 50 completed sessions per available group, 120-second maximum wait. Missing telemetry holds. Proposals must name deployment verification and explicit separate progression/rollback authorization. Full exposure has no concurrent control; require a frozen baseline. Thresholds are demonstration policy, not statistical guarantees. Never interpret proposal or memory as approval.
